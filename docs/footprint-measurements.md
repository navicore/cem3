# Binary Footprint Measurements

Optimized, **stripped** production binary size of a hello-world
program — the artifact you actually ship. Rust and Seq are built
with this repo's `[profile.release]` (opt-level 3 + LTO +
codegen-units=1) then stripped; Go uses `go build -ldflags="-s -w"`.
Go is shown for perspective as another runtime-bearing language.

The much larger default `seqc build` output is almost all DWARF
debug info (embedded in the binary on Linux, a separate `.dSYM` on
macOS) and is stripped before shipping, so it is not shown here.

Generated by `just footprint` (scripts/measure-footprint.sh); each
platform's row is refreshed when you run the recipe on that platform.
